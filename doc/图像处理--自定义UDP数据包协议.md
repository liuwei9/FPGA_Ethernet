# 自定义UDP数据包协议

## 数据包组成

UDP数据包里面的内容分为图像数据和控制命令两种

图像数据均采用RGB565或者8bit灰度值来存储

### 数据包格式

每一个数据包以包头、数据，包尾三部分组成。在数据传输过程中每一包数据都先传输包头部分，然后传输数据部分，最后传输包尾。

> 每一帧图像为一个数据包
> 每一组控制命令为一个数据包

### 包头格式
每一个数据包的包头以64bit数据0x7755_2211_3366_1155开头，以0x5511_6633_1122_5577结尾

数据部分有8字节内容，默认为0

| 0x7755_2211_3366_1155 | 控制字符 | 数据 | 0x5511_6633_1122_5577 |
| -- | -- | -- | -- |

包头协议格式如上所示

其中控制字符为8bit数据
- 0x1 代表整个包为图像数据
- 0x2 代表整个包为控制命令

#### 图像数据的包头格式

如果一个数据包要传输的内容为图像数据，那么在包头中的数据部分包括以下内容：

- 图像的长 (2字节)
- 图像的宽 (2字节)
- 协议包数量 (4字节)

| 图像的长 | 图像的宽 | 协议包数量 |
| -- | -- | -- |

#### 控制命令的包头格式

如果一个数据包要传输的内容为控制命令，那么在包头中的数据部分包括以下内容：

- 控制命令 （2字节）

| 控制命令 | 含义      |
| --      | --        |
|0x1      | Sobel算法  |
|0x2      | Canny算法  |
|0xFFFF   | 启动计算   |

### 数据格式

每一组数据最大1400字节
每一组数据最开始为4字节的帧号，然后是2字节的长度（专指有效数据的长度）计算公式为每一组数据的实际长度-4-2

对应1080P的RGB565数据，总字节大小为1920\*1080\*2 = 4147200
每一组数据传输1392 + 4 + 2字节，总共需要传输2979次，然后还剩432字节
最后再传输一组432 + 4 + 2字节的包

每一个数据包的包尾以200bit数据0x6633_7755_3322_4411_7733_9988_1144_6633_3366_4411_8899_3377_11
